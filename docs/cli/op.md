# mydc op: 보낸 작업 확인·재개

바꾸는 명령은 보내기 전에 작업 ID를 하나 만들어 이 컴퓨터의 `~/.mydc/ops/`에 적고 화면에 보여 준다. 명령이 끊기거나 응답을 못 받아도 새 명령을 다시 보내지 않는다. 같은 ID로 서버에 묻고, 필요하면 저장해 둔 같은 요청을 다시 보낸다. 서버는 같은 ID의 요청을 한 번만 실행한다.

| 명령 | 하는 일 |
|---|---|
| `mydc op list` | 이 컴퓨터에서 보낸 작업을 최근 것부터 보여 준다 |
| `mydc op show ID` | 서버에 그 작업이 어떻게 됐는지 묻고 기록을 고친다. 끝난 작업은 다시 묻지 않는다 |
| `mydc op resume ID` | 저장한 같은 요청을 다시 보내고 끝날 때까지 따라간다 |
| `mydc op prune [--older-than 168h] [--dry-run]` | 끝난 작업(done·failed)을 목록에서 지운다. 진행 중이거나 결과를 모르는 작업은 남긴다 |

ID는 전체를 쓰거나, 겹치지 않으면 앞 4글자 이상만 써도 된다.

## 상태

| 상태 | 뜻 |
|---|---|
| `sending` | 보내기 직전에 저장했다. 서버가 받았는지는 `op show`로 물어야 안다 |
| `accepted` | 서버가 받았고 아직 진행 중이다 |
| `done` | 끝났다 |
| `failed` | 실패로 끝났다. 내용은 `detail`에 있다 |

목록은 이 컴퓨터와 이 Linux 사용자의 것이다. 다른 컴퓨터에서 보낸 작업은 보이지 않는다. 기록에는 공개 정보(ID, 명령, context, 상태)만 있고, 서명한 원 요청과 비밀 입력 복구 정보는 각 명령의 journal에 따로 있다.

지금은 `op` 틀만 있다. 각 명령 그룹을 새 체계로 옮길 때 그 그룹의 작업이 여기에 기록된다.
