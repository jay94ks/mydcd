## 자원·삭제 차단 공개 projection

[관리 자원 조회](../../reference/resource-queries.md)의 목록은 기존 Catalog/Apps Binding/Volume consumer/Checker Uses/Vault approval usages와 원 DNS owner 관측에서 파생한다. 독립 자원·목록 상태 저장소를 만들지 않는다. 종료 중인 원 참조는 실제 반환/서명 종료 후에만 사라지며, Volume retained move 원본은 삭제 수락과 실제 Gone을 구분한다. 조회는 생성·adopt·새 native 실행·참조 반환을 수행하지 않는다. route endpoint 공개 발견은 활성 named TUN 멤버 이름에 한정하고 원 private Bridge/CIDR/owner/generation을 노출하지 않는다.
