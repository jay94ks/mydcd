## 서비스 POST·Git probe 메시지

User(kind1) `service-call`의 Request는 typed `{Schema:1,Method,Nonce,Params:{Tenant,Call:{App,Service,Port,Path,Method:"POST",Headers?,TimeoutMS,Scheme?,InsecureSkipVerify?},Input:{Length,Digest}}}`다. Body는 JSON에 싣지 않고 kind2 `continue` 뒤 기존 User kind4(24KiB chunk)의 원 digest/순차 offset으로 최대256KiB를 보낸 뒤 EOF한다. 길이·전체 SHA-256·EOF 이전에 효과를 내지 않는다. 최종 `Reply.Data`(servicecall.Result) `{Code?,Status?,Headers?,Body?,Task?,Node?,ElapsedMS}`에서 Body는 최대64KiB base64, Header는 Content-Type만이다. 호출 권한은 현재 CallService이고 timeout/응답 유실 뒤 자동 재전송하지 않는다. User `cd-probe`는 typed `{Schema:1,Method,Nonce,Params:{Tenant,Probe:{App,Repository,Branch,Path,Credential?}}}`, EOF 뒤 `Reply.Data:{Code,Commit,Node,Size}`를 반환한다. 현재 Deploy 권한·사용자당10회/분이며 CD/app을 바꾸지 않는다. [전체 메시지 형식·HTTPS/tenant CA·오류 코드](../service-diagnostics.md)를 따른다. Unix와 QUIC의 사용자 계약은 같다. member 전용 `service-call-permit`은 Unix 허용 메시지가 아니다.
