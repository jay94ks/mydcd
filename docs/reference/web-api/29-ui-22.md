## 작업 공간 종료 (UI-22, 시스템 관리자)

| 끝점 | 본문 → action |
|---|---|
| `POST /tenants/{t}/retire` | `{opId, expected}` → `begin-tenant-retirement`(`control.TenantRetirementSelection{Tenant, Operation}`). Operation은 데몬이 `"retire-" + opId`로 만든다(같은 opId는 같은 종료). `expected`는 종료 상태의 `revision` |
| `POST /tenants/{t}/retire/finish` | `{opId, expected}` → `finish-tenant-retirement`. Operation은 데몬이 지금 종료 상태에서 읽어 넣는다. 종료 중이 아니면 409 `not-retiring`(저장 안 함). `expected`는 시작 뒤 바뀐 `revision` |

응답은 `{op}`이고 같은 `opId` 규칙은 공유 자원 만들기와 같다(본문 digest에 action이 들어가 시작과 마치기에 같은 opId를 쓰면 409 `op-conflict`). 판단은 mydcd가 한다: 활성이 아니면 시작이, 소유자 보고가 덜 끝났거나 남은 것이 있으면 마치기가 op `failed`다. 화면은 `ready`가 true일 때만 마치기를 연다.
