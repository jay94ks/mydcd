## 설정 변경 기록 (UI-A3)

`GET /audit?tenant=&before=&limit=` → `{items:[{id, at, user, username, tenant, area, action, target, before, after}], next}`. 최신순, `limit` 1..1000(기본 100), 다음 쪽은 `before=<next>`. 시스템 관리자는 전부, 다른 사용자는 자기가 속한 작업 공간의 기록만 본다(작업 공간이 없는 시스템 설정 기록은 안 보임). 지우는 끝점은 없고 보관 기간(기본 1년) 뒤 사라진다. 토큰·비밀은 바뀐 사실만 남는다.

지금 기록하는 것: 웹 앱 설정 바꾸기(`web-settings`), 봉인 파일 초기화(`seal`), 자동 작업 계정 키 만들기·지우기(`automation`), 백업 내려받기·되살리기 대기·취소(`web-backup`), 보관된 앱 완전 삭제(`archived`). AI·외부 DNS·인증서·웹훅 설정은 각 기능과 함께 붙는다.
