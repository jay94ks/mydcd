# 주요 알고리즘

| 설명 | 핵심 질문 |
|---|---|
| [합의·CAS·원 요청](consensus-and-requests.md) | 어떤 변경을 확정하며, 중복/불명 결과를 어떻게 보존하는가? |
| [Reconcile·참조·종료](reconciliation.md) | 목표를 실제 효과에 연결하고 언제 자원을 반환하는가? |

제품은 채택한 Raft 라이브러리로 관리 변경을 확정한다. 직접 구현하는 부분은 결정적 업무 상태 전이·요청 식별·허가·자원 참조와 실제 효과의 정산이다. 개발 방법과 Mock/재검증 절차는 개발 문서에서 별도로 관리한다.
